# Tech stack logos

Logo dipakai dari folder ini (`/stack`). Nama file harus sama dengan yang di `src/data/portfolio.js` techList.

Saat ini ada: `Bootstrap.svg`, `Postgresql.svg`, `nodejs.svg`, `strapi.svg`.

Tambahkan file lain sesuai daftar di portfolio.js (mis. `laravel.svg`, `react.svg`, `vue.svg`). Jika file tidak ada, yang tampil fallback huruf pertama nama tech.
